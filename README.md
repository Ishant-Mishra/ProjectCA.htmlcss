# Personal Portfolio — HTML & CSS Practice

A single-page portfolio website built with HTML and inline CSS to practice structuring a personal website.

## Sections

- Introduction and About Me
- Skills
- Project summaries
- Resume section
- Contact section

## Run Locally

No build tools are required. Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/Ishant-Mishra/ProjectCA.htmlcss.git
cd ProjectCA.htmlcss
```

## Notes

- This is a beginner-level static website; it does not use a backend.
- The resume link is currently a placeholder and should be replaced with a real file or destination before publishing.
- Review which contact details you want to make public before deploying the page.
